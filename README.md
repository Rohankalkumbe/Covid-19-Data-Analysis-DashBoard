# 📊 COVID-19 Data Analysis Dashboard

## 📌 Overview
This project presents a **COVID-19 Data Analysis Dashboard** built using **Power BI**. The dashboard provides insights into global COVID-19 trends, including **total cases, deaths, recoveries, and regional impact**.

## 📂 Dataset Information
- **Dataset Name:** COVID-19 Dataset
- **Data Source:** WHO & Government Reports
- **Columns:**
  - Country
  - WHO Region
  - Confirmed Cases
  - Total Deaths
  - Total Recovered
  - Active Cases
  - Weekly Case Increase

## 📊 Key Metrics & Insights
- **Total WHO Regions:** 6
- **Total New Cases:** 229K
- **Total Active Cases:** 6M
- **Highest Death Country:** USA
- **Fastest Growing COVID-19 Region:** Europe (56% weekly increase)
- **Death vs. Recovery Trends by Country**
